Mỗi người tự vẽ **đủ các loại sơ đồ chính** cho mảng của mình, nên ai cũng luyện đủ mọi loại.

| :--- | :---: | :---: | :---: | :---: | :--- |

| Activity | A7 | B7 | C7 | D7 | |
